# AWS 웹 서비스 인프라 아키텍처 


![아키텍처](architecture.png)

서울 리전의 VPC 안에 Public Subnet과 EC2 웹 서버를 구성합니다. 인터넷 연결은 IGW와 기본 라우트로 제공하고, Security Group으로 HTTP와 SSH 접근 범위를 분리합니다. 리소스 관리에는 IAM 최소권한을 적용하며, AWS 조회 원본·HTTP 응답·서버 로그를 연결해 구성을 검증합니다.

용어 설명: [Glossary](glossary.md)

색상 규칙: 01 웹 요청은 파랑, 02 웹 응답은 초록, 03 SSH 서버 관리는 보라, 04 서버가 시작하는 외부 통신은 주황이다. 상단 화살표와 범례, 하단 흐름 카드의 테두리·제목·경로 문장에 같은 색을 적용했다. 번호도 함께 사용해 색상에만 의존하지 않는다. 회색 점선은 설정 관계이며 선 교차는 연결을 뜻하지 않는다. IAM 관리 패널은 중립색으로 구분한다.


## 설계 원칙

- 방문자 → Internet Gateway → EC2/Nginx의 주 경로를 한 번만 표현한다.
- AWS Cloud 안에 VPC, VPC 안에 Public Subnet, Subnet 안에 EC2를 배치한다.
- IGW는 VPC에 연결하며, Public Route Table은 Subnet에 연결한다.
- Route Table은 트래픽 중계 서버가 아닌 경로 규칙이다. SG는 EC2의 네트워크 인터페이스에 적용되는 트래픽 규칙이다.
- 퍼블릭 IPv4와 기본 경로 및 SG가 함께 충족되어야 한다. 기본 NACL 허용 상태도 배포 시 확인한다.
- SG의 80번은 전체 공개, 22번은 운영자 공인 IP /32만 허용한다. SSH는 IP 허용 외에도 정상적인 키 인증이 필요하다.
- IAM은 관리자가 AWS API로 자원을 다루는 권한이다. HTTP 요청 경로와 분리한다.
- 응답과 서버의 외부 통신 모두 같은 IGW를 사용한다. 아웃바운드 기본 경로는 0.0.0.0/0 → IGW이다.
- 단일 AZ, 단일 EC2 실습 구조이다. 고가용성 운영 구조는 아니다.



## 통신 흐름 검토 및 보완

1. 웹 요청: 방문자 → 인터넷 → IGW → EC2 ENI의 SG 검사(TCP 80) → Nginx → / 또는 /health. IGW는 EC2의 퍼블릭/프라이빗 IPv4 매핑을 수행한다.
2. 웹 응답: Nginx → EC2 ENI → Subnet의 기본 라우트(IGW) → IGW → 인터넷 → 방문자. SG는 상태 기반이므로 허용된 요청의 응답을 허용한다.
3. SSH: 운영자 → 인터넷 → IGW → SG 검사(TCP 22, 운영자 IP /32) → sshd. 키 인증 후 접속하며 반환 트래픽은 IGW를 통해 운영자에게 돌아간다. Nginx를 거치지 않는다.
4. 아웃바운드: EC2 → SG 아웃바운드 검사 → Subnet 기본 라우트 → IGW → 인터넷 → 외부 서비스. 응답은 IGW를 통해 EC2로 돌아오며 SG의 연결 추적으로 허용된다. 예시는 HTTPS 443 통신이며 이름 해석에는 VPC DNS를 사용한다.

위 순서는 서비스 이해를 위한 논리적 흐름이며 모든 패킷 처리 단계를 나타내는 도식은 아니다. Route Table과 SG는 독립된 중계 서버가 아니다. 기본 NACL은 양방향 허용을 전제하며 실제 배포에서 확인한다. OS 방화벽과 리스닝 주소도 접속 검증에서 확인한다. EC2는 단일 AZ에 배치하며, EBS는 해당 AZ의 EC2에 연결한다.

## 용어 정리 

| 개념 | 쉬운 비유 | 정확한 역할 |
| --- | --- | --- |
| VPC | 가게가 들어설 전용 부지 | AWS 안에 만드는 논리적으로 분리된 가상 네트워크 |
| Subnet | 부지 안의 한 구역 | VPC 주소 범위를 나눈 네트워크. 하나의 AZ에 위치 |
| Route Table | 길 안내판 | 목적지 주소에 따라 트래픽을 보낼 대상을 결정 |
| Internet Gateway | 인터넷으로 연결되는 출입구 | VPC에 연결되어 인터넷 통신과 퍼블릭 IPv4 매핑 제공 |
| EC2 | 빌린 컴퓨터 | Nginx와 SSH 서버를 실행하는 가상 서버 |
| Security Group | 출입문 경비원 | EC2 ENI에 적용되는 상태 기반의 네트워크 허용 규칙 |
| IAM | 직원별 업무 권한 | 누가 AWS에서 어떤 리소스에 어떤 작업을 할 수 있는지 제어 |
| EBS | 컴퓨터의 저장장치 | EC2에 연결해 OS·웹 파일·로그를 저장하는 블록 스토리지 |
